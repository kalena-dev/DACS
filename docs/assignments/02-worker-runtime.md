## Execution contract

- Persist assignment receipt and unreported results in a local journal. Bind commands to attempt generations and preserve source/policy/contract revisions.
- Prepare independent branches/workspaces. Remote machines use separate clones/repository instances. Worktrees are editing isolation, not security containment.
- Run pinned OMP through JSONL RPC; correlate requests, drain output and handle UI/tool messages. Register DACS host tools. Disable native spawning paths in the managed profile so scheduled children are admitted by DACS.
- Return long-running job/delegation IDs promptly. Outcomes arrive later through durable messages. No tool call should need to survive a restart. Restore pending DACS obligations when attaching/restarting an OMP session.
- An OMP yield or settled state does not complete a DACS attempt with pending children/jobs. Require explicit submission and reconciled obligations. Never release a waiting parent's reservation for another session.
- Count OMP tools, build/test processes and compiler allocations against physical-host capacity; do not count a VM as another independent machine.

On coordinator loss, finish only admitted work within existing reservations, retain results and wait. Do not expand reservations or start new cross-machine work. Report unavailable dependencies explicitly.

The coordinator may replace a replayable workspace-only task after lease expiry; external/host-level effects wait for explicit abandonment. A heartbeat loss alone is insufficient. Reservations on the unreachable worker remain held. On reconnect, stop fenced attempts, reconcile processes/results and then release their allocations. Fencing cannot undo arbitrary shell effects.

Cancellation stops admissions and reports terminal cancellation only after owned execution is terminated/reconciled and Person 1 has resolved any publication outcome. Ordinary window close and permission reduction drain admitted work instead; show pending changes and still-active broader permissions. Emergency cancellation is separate.
